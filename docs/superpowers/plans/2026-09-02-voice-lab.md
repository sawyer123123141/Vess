# Voice Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a repeatable local voice benchmark harness that replays identical audio/text through Vess endpointing, Whisper, TTS, and cancellable synthesis paths.

**Architecture:** Keep benchmark logic in a small `voice_lab` package and expose it through one `tools/voice_lab.py` CLI. Reuse production `UtteranceAssembler`, `_make_transcriber`, TTS factory, and existing `tools/benchmark_tts.py`; CI uses synthetic/fake engines only while real model measurements run locally.

**Tech Stack:** Python 3.11, stdlib `json`/`wave`/`threading`/`argparse`, NumPy, existing Vess audio/TTS modules.

**Spec:** `docs/superpowers/specs/2026-09-02-voice-lab-design.md`

## Global Constraints

- Do not modify live Vess behavior or repository config defaults.
- Do not add runtime dependencies.
- Corpus input is mono 16 kHz PCM WAV only in v1.
- Reuse the production endpointing/transcriber/TTS construction paths.
- CI must not load Whisper or Chatterbox.
- Every experiment writes JSON beneath `artifacts/voice-lab/`.
- No automatic network download, resampling, config mutation, subjective scoring, or parallel GPU model instances.
